# Lucas Game / Jogo do Lucas

This is a starter Godot 4.x project initialized for Lucas.
Este é um projeto inicial da Godot 4.x inicializado para o Lucas.

---

## English Version

### How to Play / Run
1. Download and install **Godot Engine 4** (version 4.0 or newer).
2. Open the Godot Project Manager.
3. Click **Import**, navigate to this folder, and select the `project.godot` file.
4. Click **Edit** to open the project in the editor.
5. Press **F5** (or the Play button at the top right) to run the game!

### Controls
* **Move:** Use **W, A, S, D** or **Arrow Keys** on your keyboard.
* **Controller:** You can also use the Left Analog Stick or D-Pad on a gamepad.

### Project Structure
* [project.godot](file:///home/marcos/IDE/lucas/project.godot) - Project settings and configuration.
* [main.tscn](file:///home/marcos/IDE/lucas/main.tscn) - The main game scene containing the background and instanced player.
* [player.tscn](file:///home/marcos/IDE/lucas/player.tscn) - The 2D Player scene with collision and sprite placeholders.
* [player.gd](file:///home/marcos/IDE/lucas/player.gd) - The GDScript code governing player movement and acceleration/friction.
* [icon.svg](file:///home/marcos/IDE/lucas/icon.svg) - Game icon.

## Versão em Português

### Como Jogar / Executar
1. Baixe e instale a **Godot Engine 4** (versão 4.0 ou mais recente).
2. Abra o Gerenciador de Projetos da Godot.
3. Clique em **Importar**, navegue até esta pasta e selecione o arquivo `project.godot`.
4. Clique em **Editar** para abrir o projeto no editor.
5. Pressione **F5** (ou o botão Play no canto superior direito) para rodar o jogo!

### Controles
* **Mover:** Use as teclas **W, A, S, D** ou as **Setas do Teclado**.
* **Controle/Gamepad:** Você também pode usar o analógico esquerdo ou o direcional (D-Pad).

### Estrutura do Projeto
* [project.godot](file:///home/marcos/IDE/lucas/project.godot) - Configurações e metadados do projeto.
* [main.tscn](file:///home/marcos/IDE/lucas/main.tscn) - Cena principal do jogo contendo o fundo e o jogador instanciado.
* [player.tscn](file:///home/marcos/IDE/lucas/player.tscn) - Cena 2D do jogador com colisões e visualizadores.
* [player.gd](file:///home/marcos/IDE/lucas/player.gd) - O script GDScript que controla a aceleração, fricção e movimentação do jogador.
* [icon.svg](file:///home/marcos/IDE/lucas/icon.svg) - Ícone do jogo.
